WHY MACSHIFT?

Two Macs, two independent input states.

In English

Why is this needed?

Even when you connect to another Mac through macOS Screen Sharing or Jump Desktop, keystrokes are forwarded while each Mac keeps its input source and Korean composition state independently.

What can go wrong?

When those states differ, Korean text may arrive as separated Jamo instead of composed Hangul characters. Wrong-language input also interrupts typing and requires manual correction on the other Mac.

How does MacSHIFT help?

MacSHIFT uses Hammerspoon to send the Korean or English state selected on this Mac to the other Mac as an explicit key signal. Press the configured toggle shortcut once after connecting, or use a Korean/English shortcut, to align both Macs.

What changes?

MacSHIFT reduces separated Jamo and wrong-language input without a separate server, network listener, or clipboard sharing. Verified with Jump Desktop and macOS Screen Sharing.

THREE STEPS

Install, allow, type.

  1. Run ./install.sh on every Mac in the session: this Mac and the other Mac.
  2. Allow Hammerspoon in Accessibility settings.
  3. Reload Hammerspoon and press ⌃⌥H or ⌃⌥L.
⌃⌥HKorean / Hangul
⌃⌥LEnglish / Latin
⇧RToggle from this Mac’s state

Sync once after connecting.

Press your configured toggle shortcut once—⇧R by default. MacSHIFT uses this Mac’s current Korean or English state and applies it to the other Mac, regardless of either Mac’s starting state.

POWERED BY HAMMERSPOON

The part that makes it work.

Hammerspoon listens for shortcuts, changes macOS input sources, and carries MacSHIFT’s F18/F19 sync signals. It also lets the installer start MacSHIFT and reload its configuration immediately.

Private by design

MacSHIFT neither records typing nor reads the clipboard. The optional daily updater only checks GitHub Releases and verifies the release checksum before installation.
