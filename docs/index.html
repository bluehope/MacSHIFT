MacSHIFT synchronizes Korean and English input sources between Macs during remote sessions. Verified with Jump Desktop and macOS Screen Sharing.

View on GitHub

One small bridge

No server, SSH tunnel, clipboard access, or text capture. MacSHIFT uses keyboard events already flowing through your remote session.

Made for both sides

Install as a local controller, remote receiver, or both. Viewer and Connect roles are detected automatically when available.

HOW IT WORKS

Type once. Match both Macs.

THREE STEPS

Install, allow, type.

  1. Run ./install.sh on both Macs: the Mac you connect from and the Mac you connect to.
  2. Allow Hammerspoon in Accessibility settings.
  3. Reload Hammerspoon and press ⌃⌥H or ⌃⌥L.
⌃⌥HKorean / Hangul
⌃⌥LEnglish / Latin
⇧RToggle from local state

Private by design

MacSHIFT neither records typing nor reads the clipboard. The optional daily updater only checks GitHub Releases and verifies the release checksum before installation.
